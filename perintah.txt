Tujuan Aplikasi:
Bangun aplikasi web "J CV Builder" (SaaS pembuat & editor CV ATS 1-kolom) multi-user yang aman, profesional, dan siap dideploy ke Vercel dengan database & autentikasi cloud Supabase.

--------------------------------------------------------------------------------
1. TECH STACK & INTEGRASI
--------------------------------------------------------------------------------
- Framework: React.js (Vite)
- Styling: Tailwind CSS
- Icons: Lucide-React + inline SVG untuk brand icons (LinkedIn, GitHub)
- PDF Renderer: html2pdf.js + optimasi CSS @media print
- Database & Autentikasi: Supabase (@supabase/supabase-js) dengan PostgreSQL & Row Level Security (RLS)
- Hosting: Vercel (SPA routing dengan vercel.json)
- Branding: "J CV Builder" (Single Column ATS Resume Platform)

--------------------------------------------------------------------------------
2. SPESIFIKASI FITUR & ATURAN LOGIKA KETAT
--------------------------------------------------------------------------------

A. GERBANG AKSES OTENTIKASI KETAT (ACCESS GATE):
   - Pengguna WAJIB login terlebih dahulu sebelum dapat mengakses editor atau melihat isi web.
   - Jika pengguna belum terautentikasi (`!currentUser`):
     * Tampilkan layar penuh Halaman Masuk / Daftar Akun (`AuthScreen`) yang modern dan profesional.
     * Tidak boleh menampilkan formulir editor atau preview dokumen sebelum user berhasil login/register.
   - Sediakan form login (Email, Password, Show/Hide Password, Validasi, Error Alert) dan form register (Nama Lengkap, Email, Password, Konfirmasi Password).
   - Setelah login berhasil, arahkan langsung ke Workspace Utama CV dengan data resume milik user tersebut.

B. PENCEGAHAN BUG URL SUPABASE (SANITASI URL OTOMATIS):
   - PENTING: Sering terjadi kesalahan input di mana user menempelkan URL dengan akhiran `/rest/v1/` sehingga memicu error "Invalid path specified in request URL".
   - Klien Supabase (`supabaseClient.js`) WAJIB memiliki fungsi sanitasi URL otomatis sebelum inisialisasi:
     ```javascript
     const rawUrl = (import.meta.env.VITE_SUPABASE_URL || '').trim();
     const sanitizedUrl = rawUrl
       .replace(/\/rest\/v1\/?$/i, '')
       .replace(/\/auth\/v1\/?$/i, '')
       .replace(/\/+$/, '');
     ```
   - Pastikan variabel `VITE_SUPABASE_URL` dan `VITE_SUPABASE_ANON_KEY` dimuat dari `.env`.

C. DATA AWAL CV WAJIB KOSONG (EMPTY DEFAULT):
   - Jangan mengisi formulir dengan data dummy (tidak boleh ada nama orang atau riwayat bawaan di form awal).
   - Semua kolom input teks WAJIB menggunakan atribut `placeholder="Contoh: ..."` sebagai panduan format bagi pengguna (contoh: `placeholder="Contoh: MUHAMMAD ARYA PRATAMA"`, `placeholder="Contoh: Universitas Indonesia"`, dll).
   - Sediakan tombol opsional "Muat Contoh" untuk melihat sampel demo dan "Kosongkan" untuk mereset formulir.

D. DASHBOARD PENGELOLAAN MULTI-CV (BANYAK CV PER AKUN):
   - Pengguna dapat membuat dan mengelola LEBIH DARI 1 CV di database cloud.
   - Sediakan modal/dashboard "CV Saya":
     * Daftar seluruh resume milik user beserta judul dan tanggal update terakhir.
     * Tombol "+ Buat CV Baru" (membuat resume kosong baru di cloud).
     * Tombol "Buka CV" (memuat resume ke editor).
     * Tombol "Duplikasi" (membuat salinan resume).
     * Tombol "Hapus" (menghapus resume dengan dialog konfirmasi).
   - Fitur Auto-Save ke cloud Supabase (debounced 1.5 detik) dengan indikator status ("Tersimpan di Cloud", "Menyimpan...", "Perubahan Belum Disimpan").

E. PENGHAPUSAN FITUR IMPORT JSON:
   - Hapus semua tombol import atau modal parser JSON file yang ada sebelumnya.
   - Penyimpanan data difokuskan 100% pada database Supabase per akun user.

F. LIVE PREVIEW DOKUMEN A4 & EXPORT PDF:
   - Pratinjau real-time 1-kolom ATS standar A4 (210mm x 297mm) dengan tanggal & lokasi rata kanan (`flex justify-between`).
   - Kontrol preview: Zoom In, Zoom Out, Fit (90%), pemilihan font (Inter / Merriweather), pilihan warna aksen, dan spasi (Kompak 1 Lembar / Normal).
   - Tombol "Export PDF" via html2pdf.js (margin 10mm, skala 2.5x) dan tombol "Print" via browser native print.

G. SKEMA DATABASE SUPABASE (POSTGRESQL + RLS):
   Sediakan file `supabase_schema.sql`:
   ```sql
   CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

   CREATE TABLE IF NOT EXISTS public.resumes (
       id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
       user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
       title TEXT NOT NULL DEFAULT 'Resume ATS Baru',
       content JSONB NOT NULL DEFAULT '{}'::jsonb,
       created_at TIMESTAMPTZ NOT NULL DEFAULT timezone('utc'::text, now()),
       updated_at TIMESTAMPTZ NOT NULL DEFAULT timezone('utc'::text, now())
   );

   ALTER TABLE public.resumes ENABLE ROW LEVEL SECURITY;

   CREATE POLICY "Users can select own resumes" ON public.resumes FOR SELECT USING (auth.uid() = user_id);
   CREATE POLICY "Users can insert own resumes" ON public.resumes FOR INSERT WITH CHECK (auth.uid() = user_id);
   CREATE POLICY "Users can update own resumes" ON public.resumes FOR UPDATE USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);
   CREATE POLICY "Users can delete own resumes" ON public.resumes FOR DELETE USING (auth.uid() = user_id);
   ```

H. DEPLOYMENT VERCEL:
   - Buat berkas `vercel.json` untuk routing SPA:
     ```json
     {
       "framework": "vite",
       "rewrites": [
         { "source": "/(.*)", "destination": "/index.html" }
       ]
     }
     ```
